# Format choice and acquisition

The goal is reliable local retrieval of passages with context and locators.
Token savings come from focused reading, not from a file extension by itself.

- **EPUB:** Default when the available text editions appear comparable. Often a
  single package with structured XHTML, metadata, navigation, chapter order,
  notes, and images. Inspect the actual text and spine; do not assume every
  export has good structure or all illustrations. Keep the EPUB as received.
- **Word/DOCX:** Strong choice when available and more useful for this title,
  especially for usable paragraphs, headings, notes, or tables. Bookshare may
  deliver a ZIP of numbered parts. Preserve every part, inspect boundaries,
  and give each a descriptive name. A large part is not necessarily a chapter.
- **DAISY text:** Fallback when EPUB/Word are missing or defective, or it
  preserves needed content better. Choose the image-bearing option when
  available and relevant. Inspect the actual XML/HTML and reading structure.
  The current shared-library audit does not support it automatically; follow
  the catalog guidance rather than falsely declaring it integrated.
- **PDF or other text formats:** Consider only when actually offered and useful.
  Prefer a reliable text layer and meaningful page locators; scans need extra
  inspection. Do not assume PDF is a standard option for each title.
- **MP3, DAISY Audio, BRF:** Use for a requested listening or braille experience,
  not as the default substitute for searchable research text.

Do not download several formats preemptively. If the first authorized text
format proves incomplete or unusable, obtain a better available format of the
same requested edition and explain the substitution. Preserve the flawed source
and verification notes outside the completed shelf; do not call it complete.
If content or edition identity changes, resolve the user's intended scope.

Official Bookshare help, checked October 30, 2026:

- [Available formats](https://www.bookshare.org/help-and-learning-articles/what-format-are-bookshare-books-available-in).
- [Downloading and extracting books](https://www.bookshare.org/help-and-learning-articles/how-do-i-unzip-bookshare-books):
  choose the title's format and Download; My History may show In Progress, then
  an Available action to save the prepared file. Confirm current labels in UI.
- [Downloading books in Word](https://www.bookshare.org/help-and-learning-articles/how-to-download-and-read-books-in-word).
- [Download preferences](https://www.bookshare.org/help-and-learning-articles/how-can-i-modify-download-preferences):
  DAISY with images, where available, differs from text only. These are global
  account preferences, not settings the skill should change for a single book.

Use the title's current signed-in format menu as the availability evidence.
A public listing, past download, or generic help page does not guarantee
current account access to a particular format.
