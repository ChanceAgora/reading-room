# Anchor saved selections to source coordinates

Exact citations and research-use records identify source blocks, Unicode
code-point ranges, and source fingerprints. Quotation text is reconstructed
and validated against those coordinates; repeated phrases are not identities.
Saved selections remain in durable private state across derived-index rebuilds.

Repaired section boundaries can change indexed passage IDs without changing
source text. Preserve historical passage extents and resolve old links only
when their exact source membership and text remain demonstrably unchanged.
Changed or missing sources retain unresolved history rather than silently
transferring a correction to a nearby contribution. Citation target extent is
separate from metadata provenance, and whole-unit citations never borrow the
first indexed passage's narrow corrections.
